# qemu.txt: the sources of the assignment cases' outer QEMU, which
# build_qemu.sh builds, one to a line: a name, the version, the URL and the
# SHA-256.
#
# The tarball's digest is the one tests/assign/Readme.md has given since the
# patch was written. The packages are Ubuntu 26.04's, from Launchpad's
# librarian, which keeps a version after the archive drops it; each one's
# SHA-512 was checked against the one the archive's signed index lists. The
# development packages give the headers, the pkg-config files and the link
# names; the runtime packages give the libraries the emulator is linked
# against and run with. Ninja and pip come with them, since the build needs
# no package of the host's but Python and a C compiler.
