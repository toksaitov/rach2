# agy and Muse Code

* Both are signed in only in the owner's accounts on the Mac. Each reviews every milestone's plan on its own, beside Codex and Fable, with the questions `AGENTS.md` gives. Otherwise ask them after Fable and Codex, Muse before agy, for what those leave open or disagree on; they do not review a milestone's code. One job at a time, a narrow prompt, and a read-only job; work that changes files goes to a worker loop or Codex. Treat one as unavailable only when it says so.
* agy, Google's Antigravity CLI, runs as an interactive session in a tmux session of its own, since its headless `agy -p` is flaky: `tmux new-session -d -s agy -x 200 -y 50 -c CHECKOUT 'agy --mode plan'`; plan mode reads and does not edit. Write the prompt to a file under `build/flow/coordinator/second-opinion/`, send `Escape` to clear any banner, then `tmux send-keys -t agy -l 'Read FILE and answer it.'` and `tmux send-keys -t agy Enter`. Once its input line returns, keep the answer with `tmux capture-pane -t agy -p -J -S - > ANSWER` and kill the session. Its default is Gemini 4 Argon at medium effort (`~/.gemini/antigravity-cli/settings.json`); a hard problem passes `--model gemini-4-argon-high`, and `agy models` lists the others. The prompt tells it to read `AGENTS.md`.
* Muse Code answers one prompt with `muse exec --workspace DIR --trust-workspace --disable-write "PROMPT" < /dev/null > ANSWER 2> ERR`, or `--prompt-file FILE` for a long prompt. `--trust-workspace` loads `AGENTS.md` as its rules (it ignores `CLAUDE.md` beside it), and `--disable-write` keeps it from editing. Its default is Muse Wonder Full, `muse-wonder-full-1.0`, at high effort (`~/.config/muse/settings.json`); a hard problem passes `--reasoning-effort xhigh`.
* The prompt gives the milestone, the files, the question and what would settle it, and says to use no subagents unless the problem needs them. Check every claim in the answer against the code before using it.
* On a hard question Fable, Codex, Muse and agy work in rounds, Fable first, agy as far as its limit allows. Each round's prompt carries the others' last answers and the newest measurements and asks each to dispute the others; rounds go on until the cause is settled. Keep each round's prompt and answers under `build/flow/coordinator/second-opinion/`, as `roundN.txt` and `roundN-NAME.answer`.
* Run a long job in the background with the tool's own notice when it ends, and read its answer before reporting it.
