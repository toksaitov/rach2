# Milestone 3: the text and documentation standard

This milestone applied one writing standard to the Readmes, source comments, and messages printed by tools and build scripts. It recorded the standard in `CLAUDE.md` and the Codex instructions in `AGENTS.md`, revised the existing text, and added an automated check for later violations.

The work followed `plan.md` one phase at a time under the `/goal` runner, with an independent Codex review after each phase. The phases covered policy and an advisory checker (0), punctuation and Markdown (1), vocabulary and voice (2), messages (3), frequently read Readmes (4), foundation and newer C comments (5 and 6), the header audit (7), and enforcement of the text-style check (8). Each phase changed only text, demonstrated that behavior was unchanged, and ended in one scoped commit.
