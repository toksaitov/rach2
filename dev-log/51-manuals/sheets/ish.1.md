# ish(1)

NAME: ish - the freestanding command shell of the test and os-simple images. Source: ish/Readme.md.
* A static i386 program with its own startup code and system-call wrappers, linking no C library; one command at a time; not a POSIX shell, no script language. Interactive mode reads standard input to end of file with no prompt; the input buffer is 255 bytes, the argument array 255 tokens. `ish -c 'COMMAND'` runs one command (only `argv[2]`) and exits with its status. The parser splits on ASCII whitespace: no quotes, escapes, variables, globbing, pipelines, lists, subshells or background jobs; `<` and `>` as separate tokens redirect an external command's standard input and output (output created or truncated at mode 0644); a builtin's streams are not redirected. Builtins: `cd [DIR]` (`HOME` when none; 0 or 1), `exit [STATUS]`. An external command is tried as written, then through each element of `PATH`, empty elements skipped (a path at most 1024 bytes); the child inherits the environment; `-c` reports the child's status, 127 when no path resolves, 126 when it cannot start, `128 + SIGNAL` on a signal death; interactive mode discards statuses.
* Where it runs: `/ish` and `/bin/sh` on the test image, `/bin/sh` on os-simple.
* SEE ALSO: sh(1), rach2(7).
