# rach2-install(8)

NAME: rach2-install - install this system onto a disk, or update an installed one. Source: utils/rach2-install.txt, which is the whole reference, written at milestone 49 in the shape of a page and corrected on 2026-09-19 against utils/rach2-install in three places (no KRFFS root beside the ext2 one; --update grows the root, which touches the table entry; --update saves recovery, not the fallback, and cancels an armed trial before the write); convert it to mdoc without changing a fact, and where the text and the script disagree, the script decides. Sections: NAME, SYNOPSIS (`rach2-install [--source DIR]`, `rach2-install --update IMAGE DISK`), DESCRIPTION (the questions in order as a tag list, the archive, the write order, the demonstration accounts, `--update` whole), EXIT STATUS (0 when the disk carries the system, or the new root is on the disk and armed; anything else a failure with the reason on stderr, nothing written after a failure before the write), EXAMPLES from the project Readme (`ssh -i $RKEY root@ADDRESS 'rach2-install --update /tmp/root.ext2 /dev/disk0'`), SEE ALSO recovery(7), reflash(8), bootctl(8), growroot(8), disk(7). `tests/run installer`, `install`, `sealed` and `drill` run it.
