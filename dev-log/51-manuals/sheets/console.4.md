# console(4)

NAME: console, tty, ptmx, pts - the terminals. Sources: devfs.c dev_table (console 5/1, tty 5/0, ptmx 5/2, 0666; the ops == NULL rule: opening one yields the kernel console descriptor, except that /dev/ptmx makes a new master and /dev/tty resolves the caller's controlling terminal, ENXIO for a session without one); rach2/sys/tty/tty.c (the line discipline: canonical and raw modes, echo, signals ^C ^Z, the sessions and job control, TIOCSCTTY, TIOCSPGRP); rach2/sys/tty/pty.c (ptmx and /dev/pts/N: the master ring, the slave a full tty, indices reused, freed when both ends close); the kernel console is the serial port and the screen together, keyboard and serial input.
* `/dev/console`: the kernel console, screen and COM1 serial; the keyboard and serial input through one line discipline; `/dev/screenlog` sets what the kernel prints on the screen once init owns it (bootlog(4)). `/dev/tty`: the controlling terminal. `/dev/ptmx`: opens a new master; `/dev/pts/N` its slave; a network login gets one per session; the index is the lowest free.
* The ioctls answered (from ioctl(2)'s sheet: TCGETS/TCSETS family, TIOCGPGRP/TIOCSPGRP, TIOCSCTTY, TIOCGWINSZ, TIOCNOTTY if any).
* SEE ALSO: ioctl(2), getpid(2) (sessions), login(1), bootlog(4).
