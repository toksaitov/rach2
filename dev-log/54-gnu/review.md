# Milestone 54: the review

The Codex review of the whole batch ran as 55 units on 2026-09-27, each reading one part of the milestone's diff: the kernel by area, the probes, the host tests and the mutation scripts, the GNU build, the manual and the Readmes, and what was left over. This file lists every finding by its code and what became of it: FIXED, with the commit and the row that proves the fix where one can; REJECTED, with the reason; or LEFT, with why. The commits are master's.

Eight agents fixed the findings of eight areas, each on a branch of its own that was merged into master, and the session fixed the rest. The faults named are blocks of `tests/system/probe_faults.txt`, which `tests/system/probe_faults.sh` puts into the tree one at a time; each fails its row in a boot of the default suite, with the words the probe prints only then. `notes.md` says how the list was run.
