## Phases 7 to 11, what milestone 53 already did

The plan was written before milestones 51, 52 and 53. Three of its phases were
substantially done by those, and re-running them whole would re-read files the
tree has already brought to the standard. What each phase still owes:

* Phase 7, kernel comments. Milestone 53's comment round read twelve units
  against the code: the four system call arms, the boot and console path, the
  audio drivers, the block layer, four file systems, the checkers, the fuzz
  harnesses, the runner and the build. It found seven code faults behind wrong
  comments, entries 119 to 125. What it did not reach is the rest of the
  kernel: `sys/proc`, `sys/mm`, `sys/tty`, `sys/ipc`, `sys/io`, `sys/usb`,
  `sys/network`, `sys/display`, `sys/lib`, `sys/input.c`, and the file systems
  and block drivers outside those four and four, which is 82 source files.
* Phase 8, the non-kernel trees. Not reached at all: `utils/` and `ish/`, which
  is 48 source files, and the Doom port's own files.
* Phase 9, the documents. Milestone 53's phases 10 and 11 rewrote every Readme
  to the shape the plan asks for and its prose round proofread the root, kernel,
  tools, tests, host-test, system-test, VFS, KRFFS, utils and fuzz Readmes
  against the code, correcting four claims the code does not keep. The residue
  is the Readmes that round did not open: the per-subsystem ones under
  `rach2/sys`, and `ports/doom`.
* Phase 10, the verification checks. Superseded. Milestone 53 rebuilt them as
  the 22 numbered steps of `tools/verify/check.sh`, put `tools/`,
  `tests/system/` and `krffs/` under them for the first time, and added the
  size limits and the link check. The plan's paths, `tools/textcheck.sh` and
  `tools/check.sh`, no longer exist.
* Phase 11, the make graph. Superseded. Milestone 53's first phase moved the
  product rules to `mk/images.mk`, made the fingerprint an explicit step,
  proved incrementality on the testing host, and gave every host tool a rule.
  Entry 98 of the shortcomings list is the one thing it left: one `make` does
  not restage an image after rebuilding a probe it stages.
