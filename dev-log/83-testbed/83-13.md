# 83-13: the end's Lenovo runs in the release's boot

The five runs the stack's end owes the Lenovo, 78-13b's GPU conformance, 78-14b's video, 80-7b's native games, 80-9's Crysis and 83-7's test bed, with the vmexit group of kvm-unit-tests and the rows of 76's and 82's checkpoint slices that need the machine, are native cases of `tests/native`, which `tools/flow/release.sh` runs on the release's trial boot through `native-deploy run`. No case was run here; the release's boot is their first run.

## The boot

The release's trial boot binds the Intel driver: `rach2-install --i915` puts `rach2.i915` on the installed root's candidate and fallback lines, and `release.sh` passes it to an installer that has the option. `rach2/cmdline.md` now says that the driver serves Mesa and drives the display, which 78-12b showed. The display's rows of 76's slice therefore run on i915's mode at 1366x768, not on fbdrm's, as the manager decided on #4648. VT-d stays at its default, translation on for assigned devices only; each of Linux's figures the cases print beside Rach2's names its IOMMU setting where it was taken.
