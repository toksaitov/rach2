# Address and route changes on an interface

These rows describe Linux 6.12 in the initial namespace, with ordinary single-device routes, forwarding off, IPv4 secondary promotion off and IPv6 keep_addr_on_down off. Each row applies to a TAP, a TUN and a physical Ethernet card unless it names a device. A TAP has Ethernet broadcast capability. A TUN has point-to-point semantics. The IPv4 FIB derives the prefix from IFA_ADDRESS on all three. IFA_LOCAL names the interface's own address.

| IPv4 operation | Rach2 path | Linux path | Routes added, removed or kept |
| --- | --- | --- | --- |
| RTM_NEWADDR, including a peer | addr_change, netconf_add_address | inet_rtm_newaddr, fib_add_ifaddr, fib_magic | Add a kernel local /32 of host scope, even when down. When up, a primary gets a main-table link route to the masked destination, except for 0/8, its own /32 or NOPREFIXROUTE. A distinct /32 peer gets a host-length link route. A secondary shares its primary's prefix. |
| RTM_NEWADDR with broadcast | addr_change, addr_msg, netdev_is_broadcast | fib_add_ifaddr | In the local table add the given nonzero broadcast other than all ones. For a primary prefix shorter than /31 outside 0/8 also add its all-host-bits-one broadcast, even on TUN and with NOPREFIXROUTE. Both have link scope and kernel protocol. |
| RTM_NEWADDR replacing an existing IPv4 address | addr4_add, set_addr4_options | inet_rtm_newaddr, fib_modify_prefix_metric, set_ifa_lifetime | Match local address, destination prefix and mask. EXCL or an absent REPLACE fails with EEXIST. Replace updates the prefix metric, address protocol and lifetimes. |
| IPv4 address lifetime ends | netconf_expire_addresses, netconf_del_address | check_lifetime, inet_del_ifa, fib_del_ifaddr | End of preferred lifetime deprecates the address. End of valid lifetime deletes it and applies the same primary, preferred-source and last-address rules as an explicit deletion. |
| RTM_DELADDR with local, destination or both | addr_change, netconf_del_address | inet_rtm_deladdr, __inet_del_ifa, fib_del_ifaddr | Match each supplied selector. The destination selects by masked prefix and length. Delete the local and broadcast routes when no address still uses them. Deleting a primary also deletes its same-subnet secondaries by default. Other primary prefixes survive. |
| Remove one IPv4 address with others remaining | netconf_del_address | fib_del_ifaddr, fib_sync_down_addr | Remove its kernel prefix. Retain explicit direct routes, gateway routes and defaults even if the gateway has lost its connected route. A route with the departed address as its specified preferred source goes when the source ceases to be local. |
| Remove the last IPv4 address | netconf_del_address, addr_publish, netdev_route_flush | fib_inetaddr_event, fib_disable_ip, fib_sync_down_dev | Flush every IPv4 route using this device, including explicit direct, host-scope, gateway and default routes, regardless of protocol. Routes through another device and IPv6 routes survive. A subsequent address recreates only its own routes. |
| SIOCSIFADDR, including address zero | ifreq_ioctl, netconf_set_address | devinet_ioctl, inet_del_ifa, inet_set_ifa | Repeating the address does nothing. Otherwise delete the old address before inserting the new one. Zero stops after deletion. A TUN starts at /32, a TAP or card with the classful mask and conventional broadcast. Apply last-address cleanup at the deletion, even for replacement. |
| SIOCSIFDSTADDR, SIOCSIFNETMASK, SIOCSIFBRDADDR | ifreq_ioctl, netconf_set_peer, netconf_set_netmask | devinet_ioctl, inet_del_ifa, inet_insert_ifa | An unchanged value does nothing. A change deletes and reinserts the address with its new peer, mask or broadcast. A mask change updates a conventional broadcast on broadcast-capable devices and preserves a custom one. |
| RTM_NEWROUTE, SIOCADDRT | route_change, route_ioctl, netdev_route_change | inet_rtm_newroute, ip_rt_ioctl, fib_table_insert, fib_check_nh | Insert a direct or gateway route, including a direct default. Honor its protocol, scope, prefix and metric. Resolve a gateway through a suitable link route, which can itself be explicit. The legacy ioctl uses boot protocol, link scope for direct routes and global scope for gateways. |
| RTM_DELROUTE, SIOCDELRT | route_change, route_ioctl, netdev_route_change | inet_rtm_delroute, ip_rt_ioctl, fib_table_delete | Remove the entry matching the supplied selectors, including interface, gateway, metric, protocol and scope. A kernel prefix can be deleted while its address remains. A missing match leaves the table alone. |
| IFF_UP cleared or set by ioctl or netlink | ifreq_ioctl, link_change, netconf_set_up | fib_netdev_event, fib_sync_down_dev, fib_add_ifaddr | Down retains addresses and host-scope routes with a nowhere-scope next hop, including local routes. It flushes ordinary direct, broadcast, gateway and default routes regardless of protocol. Up recreates the address routes. Carrier loss alone marks next hops linkdown. |
| Interface unregistered, including last close of a nonpersistent tunnel | netdev_withdraw, drop_addresses, netdev_unregister | fib_netdev_event, fib_disable_ip, fib_sync_down_dev | Flush even the host-scope routes of the removed device. Preserve other devices. A persistent tunnel losing its last file keeps the device. |

| IPv6 operation | Rach2 path | Linux path | Routes added, removed or kept |
| --- | --- | --- | --- |
| RTM_NEWADDR or SIOCSIFADDR | addr6_change, in6_addr_ioctl, netconf_add_address6 | inet6_rtm_newaddr, addrconf_add_ifaddr, inet6_addr_add | Add a kernel main-table unicast prefix, including /128, unless NOPREFIXROUTE. Default metric 256. When the address becomes usable, install its local /128. IPv6 has no broadcast route. |
| Distinct IFA_LOCAL and IFA_ADDRESS | addr6_change, addr6_msg, route6_at | inet6_rtm_newaddr, __ipv6_ifa_notify | Add the local prefix at creation. On address readiness add the peer /128 in the main table. The IPv6 address ioctl has one address field. |
| RTM_NEWADDR replacing an existing address | addr6_change | inet6_addr_modify, modify_prefix_route | Update lifetimes, prefix-route flags and metric. Remove the old peer prefix on peer change and install or update the new prefix when requested. After a ready peer changes on a prefix shorter than /128, its old /128 stays. The new peer gets the address-length prefix. Only an address-ready notification installs a fresh peer /128. |
| RTM_DELADDR or SIOCDIFADDR, including last address | addr6_change, in6_addr_ioctl, netconf_del_address6 | inet6_addr_del, ipv6_del_addr, cleanup_prefix_route, __ipv6_ifa_notify | Match local address and prefix length. Remove the local and peer host routes. A finite prefix can outlive an explicitly deleted address until its own expiry. For a permanent address, retain a shared prefix or give it the longest remaining lifetime. Last-address removal keeps explicit routes. rt6_remove_prefsrc clears a specified preferred source once it is no longer available. |
| RTM_NEWROUTE or SIOCADDRT | route6_change, in6_route_ioctl, route6_change_row | inet6_rtm_newroute, ipv6_route_ioctl, ip6_route_add | Add a direct route, gateway route or default, with the given protocol and metric. The legacy ioctl supplies boot protocol. The default user-route metric is 1024. |
| RTM_DELROUTE or SIOCDELRT | route6_change, in6_route_ioctl, route6_change_row | inet6_rtm_delroute, ipv6_route_ioctl, ip6_route_del | Delete the matching prefix, interface, protocol, gateway and metric if supplied, including an address prefix route. A failed replacement must leave the old route in force. |
| IFF_UP cleared or set, interface removed | link_change, ifreq_ioctl, netconf_set_up, nd6_if_down, netdev_withdraw | addrconf_notify, addrconf_ifdown, rt6_sync_down_dev, fib6_ifdown | Down flushes all single-device routes through the device regardless of protocol. By default it drops its IPv6 addresses. Up configures link-local addressing and restarts discovery. Unregister always removes all device addresses and routes. |
| Carrier lost or restored | if_timers, forget_if | addrconf_notify, rt6_sync_down_dev, rt6_sync_up | Keep addresses and routes, including learned prefixes and routers, until their lifetimes expire. Nonlocal routes through the device acquire the linkdown flag on loss of carrier. |
| Router advertisement, withdrawal, address or route expiry | nd6_tick, netconf_del_address6, route6_learn, route6_tick | addrconf_prefix_rcv, addrconf_verify_rtnl, rt6_add_dflt_router, fib6_run_gc | The advertised on-link prefix and default router have independent lifetimes. SLAAC creates a local address. Its removal does not flush unrelated routes. |

The IPv4 implementations are in [devinet.c](https://github.com/torvalds/linux/blob/v6.12/net/ipv4/devinet.c), [fib_frontend.c](https://github.com/torvalds/linux/blob/v6.12/net/ipv4/fib_frontend.c), [fib_semantics.c](https://github.com/torvalds/linux/blob/v6.12/net/ipv4/fib_semantics.c) and [fib_trie.c](https://github.com/torvalds/linux/blob/v6.12/net/ipv4/fib_trie.c). The IPv6 implementations are in [addrconf.c](https://github.com/torvalds/linux/blob/v6.12/net/ipv6/addrconf.c) and [route.c](https://github.com/torvalds/linux/blob/v6.12/net/ipv6/route.c).

## Limits

Rach2 has one next hop per route and accepts device routes in the main and local tables of the initial namespace. It has no multipath or policy routing and does not expose Linux's secondary-promotion or keep-address-on-down switches. The explicit IPv4 and IPv6 tables each have 32 slots. An interface holds up to eight addresses in each family. An IPv6 prefix that outlives its address takes separate kernel memory, so a full explicit route table does not shorten its lifetime.

PCI handover on the e1000 and RTL8168 removes the addresses and routes but keeps the interface's name and index for the driver that reclaims it. Virtio removal and nonpersistent tunnel close unregister the interface.
