# Milestone 4: finishing the normalization

Milestone 3 set the text and documentation standard and brought the kernel and the high-traffic Readmes to it. This milestone carried the same standard into the rest of the in-house tree: the tests, the krffs host tools, the utils, and the ish shell. Their comments became Doxygen headers, the restating and development-diary comments were removed, the contracts duplicated between a header and its definition were stated once, and the stale or marketing Readmes were rewritten. It also widened the mechanical gate so the standard cannot regress anywhere in the hand-written tree: the convention and text checks now cover every in-house C and header, an em-dash hidden inside an echo or printf message is caught, and a leftover Phase or Part diary tag in a comment fails the build.

It was built from `plan.md`, executed one phase at a time under the `/goal` runner, with a harsh independent Codex review at each phase. The phases ran from the consistency fixes in the already-normalized kernel and docs (0) through the legacy syscall tests (1), the probes and the musl and host tests (2), the tests documentation and infrastructure (3), the krffs host tools (4), the utils (5), the ish shell and its Readme (6), and finally the gate's blind spots and the last over-80 comment lines (7). Every phase changed text only, was proved code-equal to HEAD with a comment-stripped token comparison, and ended in one scoped commit.
