# Milestone 4: finishing the normalization

Milestone 3 applied the text and documentation standard to the kernel and frequently read Readmes. This milestone applied it to the remaining in-house tests, KRFFS host tools, utilities, and ish shell. Comments were converted to Doxygen headers; restating and development-diary comments were removed; contracts duplicated between a header and definition were stated once; and stale or promotional Readmes were rewritten. The convention and text checks were expanded to every in-house C source and header. They also detect an em dash inside an `echo` or `printf` message and reject a Phase or Part diary tag left in a comment.

The work followed `plan.md` one phase at a time under the `/goal` runner, with an independent Codex review after each phase. The phases covered consistency fixes in the already normalized kernel and documentation (0), legacy syscall tests (1), probes plus musl and host tests (2), test documentation and infrastructure (3), KRFFS host tools (4), utilities (5), the ish shell and its Readme (6), and missed checks plus the remaining comments longer than 80 columns (7). Each phase changed only text, used a comment-stripped token comparison to prove the code equal to `HEAD`, and ended in one scoped commit.
