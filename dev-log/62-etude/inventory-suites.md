# Inventory of the suites and their scripts

This part of [the inventory of assertions](inventory.md) covers the 101 suites of `tests/registry`, the row scripts under `tests/system/`, and every other script, program, checker and fixture under `tests/system/` that is not a `*_mutate.sh` proof or `probe_faults.*`. The guest programs a suite runs are described in [their part](inventory-guest.md), and the host tests, style checks and proofs in [theirs](inventory-host.md).

"Completion bounds only" means that every time limit ends a hung run and judges nothing else. `scaled N` is `deadline.sh`'s bound, N seconds times `RACH2_TIMEOUT_FACTOR`. A suite named NAME-e1000 is the recipe of NAME run with `NIC=e1000`, which puts the machine on an Intel 82540EM and runs the half of the suite that tests the card; the other half, the network stack above the driver, runs only in NAME.

## The suites

* `gnu` (tests/run gnu: suites/gnu.sh, which runs gnu_rows.sh on the machine; 2048 MiB): one boot of the ordinary kernel with rach2.root=ext2 on a disk whose one partition is a copy of os-real-gnu.ext2, driven over SSH with nobody at the console. Before the rows: the root mounts as /dev/disk0p1, the login prompt appears, init starts sshd and sshd answers; root logs in by key on a machine that made its host keys on this boot; the test account logs in by key as uid 1000, and by password through ptydrive with exactly one prompt and ssh's status 0; root's password is refused by the server, not by a timeout; scp puts the rows' script on the machine and sftp fetches it back byte for byte; GNU sed's tarball reaches the machine. Then the 68 rows of ROWS, each under its own bound, a failed row not stopping the next (see The rows); sntpserver.py runs for the ntpd row. Last, a console row: root logs in through the serial port, starts tmux and runs a command whose output, TMUXPANE42, reaches the console, and the machine still answers SSH. The suite fails naming every failed row. Timing: SSH is tried every 2 s until it answers (gnu.sh:160-165), a retry measured in seconds; the waits for the root, the login prompt, sshd and the console row, and each row's bound, are completion bounds; the rows' own dependences are in their bullets. Fate: kept, T65; replaced in T32: the 2 s SSH retry by a wait for init's record that sshd started, then a bounded count of connection attempts.
