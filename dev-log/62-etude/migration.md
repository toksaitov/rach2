# The migration map

The migration map of milestone 62, task T01 of [the plan](plan.md): for each task of the plan that receives existing tests, the units of [the inventory](inventory.md) it takes. A unit's assertions, its dependence on speed and the reason for its fate are in its line in the inventory; this file is the index of the same fates by task. Each list names the part of the inventory the units are in and how many it takes from it.

## Where each unit goes

A unit that is kept goes to one task, which keeps its purpose: the conversion of the suite that runs it, the host selection of T23, the proof driver of T26 and T27, or the release of T62. A guest program goes with the suite that runs it, and a script with the suite or the host check that runs it.
