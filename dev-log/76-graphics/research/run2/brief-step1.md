# Step 1: KVM in WSL against WHPX on Windows

Row 1 of `run2-plan.md`: the same lavapipe work and the same Rach2 boot, under KVM in WSL and under WHPX on Windows. It steers the agents' environment (WSL unless Windows is about twice as fast) and task 73-16's profiles. Steps 2 to 4 run in the winner, so say which it is and by how much.

* The engines: QEMU 10.2.1 with KVM in WSL (as `testing`); on Windows the test engine's QEMU 11.1.2 build with WHPX, `D:/rach2/build/qemu/qemu-system-x86_64.exe`, and the stock QEMU 11.1.0, `C:/Program Files/qemu/qemu-system-x86_64.exe`. TCG on each as the baseline. Windows QEMU runs from SSH in session 0, with no desktop; say what that rules out.
* The same Debian 13 guest on each: one overlay per engine on the image named in `common.md`, the same CPUs (8), memory (8 GiB), disk and network devices, configured once by cloud-init as the first run did (`tonight/qemu-wsl.md`, the `seed/` and `launch.sh` beside the image). Measure, three times each, median and spread: boot to SSH; a fixed CPU job (one compile of a fixed source tree with `make -j8`); lavapipe work through Mesa 25.0.7 in the guest: `vulkaninfo --summary`, a fixed offscreen Vulkan and GL load (vkmark or vkcube offscreen for a fixed frame count, glmark2 offscreen on llvmpipe, whichever Debian has), and the guest's disk with `fio` at one fixed profile. State LP_NUM_THREADS.
* Rach2: the x86_64 kernel and system images of the release copy, `/home/testing/rach2/build/worktrees/release/build/x86_64/`, booted the way `tests/cases/machine.account.json` boots them, to the login prompt, three times under each engine and under TCG. Copy the files to Windows with their SHA-256. Count exits where the engine lets you (KVM's own statistics in WSL); with WHPX, say what can be counted.
* Read the load average beside each timing and keep it in the report; another agent may run a single niced job in WSL meanwhile, which you name if you see it. No other heavy work is to run on the testing PC during your timings.
* Close with the verdict the plan asks for: which environment wins for agents' graphics work, by what factor, and what in the plan changes.
