# The manual pages

The pages under `man/` are the system's manual, one `mdoc` file per page in the directory of its section: `man1` for programs, `man2` for system calls, `man3` for the few library interfaces that are this project's own, `man4` for devices, `man5` for file formats, `man7` for overviews and `man8` for administration. `rach2(7)` is the entry point.

`make man` renders every page with `man/render.sh`: `mandoc -T lint` at the warning level refuses a page with a fault, `mandoc -T ascii` renders it with the operating system named as Rach2, and the overstrikes the renderer marks bold and underline with are removed, since the console has no use for them. The text goes to `build/man/catN/NAME.N` and an HTML rendering to `build/man/html/NAME.N.html`, which is not committed. `man/aliases` lists the names a page answers for besides its own, one `NAME SECTION TARGET` a line: every BusyBox applet is an alias of its family page, `busybox-DIR(1)` or `(8)` for the applets of BusyBox's directory `DIR`, and every member of a system-call family is an alias of the family's page. `man/render_aliases.sh` renders each alias as a gzipped copy of its target under `catN`, under the plain name, so `man NAME` finds it without a link; BusyBox's `man` opens a page by its signature and decompresses it. The os-real RAM image is 24 MiB to hold the manual. The os-real and metal-disk images stage every `catN` directory under `/usr/share/man`, where BusyBox's `man` looks for a preformatted page before a source, and stage `/bin/col` as a script that copies its input, because `man` puts its output through `col -b -p -x` when standard output is not a terminal and the pages need no such filter. `man/recovery` lists the pages the recovery image stages, one `NAME SECTION` a line: the programs the installer and the recovery menu direct a person to, and `man(1)` itself. `mandoc` is a required build tool: `tools/setup/preflight.sh` refuses a build without it and `tools/setup/doctor.sh` names the package.

`make mancheck` runs `tools/verify/mancheck.c` over the tree, and `tests/run style` runs it too: every program the manifests stage under `/bin` and `/sbin` or through an `exec-dir` entry, every applet in BusyBox's table, and every call `rach2/sys/syscall.c` registers, with the socket operations behind `socketcall`, must have a page or an alias in its section; every alias must name a page; every page must pass `mandoc -T lint` at the warning level; and every page `man/recovery` names must exist and be staged by the recovery manifest. It prints each fault as `mancheck: detail` and fails on any.

`tests/run man` boots the os-real image and reads every staged page through a pipe, each of which must be the staged file byte for byte, and `rach2(7)` on the console under the pager, whose first and last lines must appear; then it boots the recovery image and reads its pages through the pipe the same way.
