Things to try

  1. Log in
    root  /  rach2
    The user and the password. Click the screen to type yourself.
  2. Play Doom
    doom
    Arrows move, Ctrl fires, Space opens doors, Esc is the menu.
  3. Compile a C program
    tcc -static hello.c -o hello && ./hello
    vi hello.c edits it.
  4. Read the manual
    man rach2
    170 pages. q leaves a page.
  5. Look around
    ls /bin; ps; free
    The programs, what runs, and the memory.

What this is

The small system: the Rach2 kernel with BusyBox, the musl C library, the TinyCC compiler and Doom, 40 MB, running from memory. Nothing is installed, and nothing leaves this page.

The emulator is slower than a real PC and has no network card that Rach2 drives. The full system, with a desktop, Firefox and GCC, runs in QEMU and on real hardware: see the repository.
