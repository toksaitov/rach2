# Homebrew formulae and casks a fresh Mac needs to build and verify Rach2.
# tools/bootstrap_mac.sh reads this file; make doctor checks the result. Keep
# the two in step: a name here that doctor does not check is a name nobody
# notices going stale.
#
# kind  name                 what it provides
formula i686-elf-gcc         the freestanding C compiler the kernel is built with
formula i686-elf-binutils    ld, strip and readelf for the same target
formula qemu                 qemu-system-i386, which every run script and test drives
formula pkg-config           how the krffs host tools find FUSE
formula cppcheck             required by make verify-style
formula shellcheck           required by make verify-style
formula clang-format         required by make verify-style
cask    fuse-t               FUSE for macOS, for mounting a krffs image on the host
